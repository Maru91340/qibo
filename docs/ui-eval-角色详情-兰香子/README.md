# 角色详情页 UI 设计说明 —— 以「兰香子」为样例

> 用途：提供给 AI 做 UI 评估的完整上下文。数据取自 390×844 移动视口下的实测（uni-app H5 构建，与微信小程序端同一套组件与样式），截图 17 张见同目录附件。
> 页面路由：`/pkg-character/detail?id=<角色id>`（示例：`?id=ch-96c1a22a99` 兰香子，5星·输出·暗双刀辰王朝帕米族）

## 一、页面元信息

| 项 | 值 |
|---|---|
| 适配基线 | 750rpx（≈375px 视口），页面宽度 = 视口宽，卡片左右边距 20rpx（≈10px），卡片宽 350px@375 |
| 整页高度 | **15226px**（约 18 屏，兰香子为数据最全的角色之一） |
| 主题 | 双主题（浅色默认 / 深色跟随系统），`theme-dark` 类切换；本次截图浅色为主、深色 3 张样例 |
| 圆角体系 | 卡片/面板 12px（--radius-lg .75rem），chips/按钮全圆角 999rpx，小图标 8-16rpx |
| 结构组件 | 单页面组件 `pkg-character/detail.vue`（约 620 行），无子组件拆分 |

## 三、各板块明细

### 1. 头部 hero（361px，元素渐变实底）
- **内容**：立绘大图（aspectFit、白底圆角容器 148rpx 高度带）、右上「☆收藏」胶囊钮（白色描边半透明底，收藏后变金底）、姓名（大号粗体白字）、三行元信息（来源·定位·稀有度 → 武器·阵营·种族 小字）、元素/阵营/种族 chips。
- **配色**：元素主题渐变底（兰香子=暗紫 #6c5ce7），白字；chips 白色 22% 透明底。
- **交互**：立绘点击预览大图；收藏切换。

### 2. 角色简介（130px 白卡）
- 标题「角色简介」+ 一段导语（兰香子：角色口吻自述）。标题 26rpx 粗体 ink 色，正文 23rpx ink-2，行高 1.65。

### 3. 基础属性（962px，三分组）
- 标题行右侧口径徽标 `Lv.1 → 100级满级（满阶）`；底部脚注说明双值含义。
- **基础战斗 5 项 / 进阶战斗 11 项 / 元素加成 10 项** 三组，组标题 23rpx ink-2 粗体。
- 每项 = 属性卡（2 列网格，--soft 底 14rpx 圆角）：图标(44rpx，彩色 SVG 风格) + 标签(21rpx ink-2) + 数值(23rpx 粗体 tabular-nums)。
- 数值格式：`243 → 6,045`（Lv.1 → 满级，箭头区分）；恒定值单值显示（暴击率 5.0%）。
- **已知问题**：属性图标走 csxylic 热链，源站慢时出现灰色空占位（截图 02 可见左侧图标未加载）。

### 4. 技能（1131px）
- 顶部 **Lv.1-12 横向切换 chips**（选中=品牌浅底描边加深，默认满级）。
- 每技能卡：名称(27rpx 粗体) + 类型标签（普攻/星鸣技/星决技/星携技，mini-tag 品牌浅底）+ 技能图标(72rpx) + 分级描述（随 Lv 切换数值变化，如 322%→676%）。
- 数据源：CBT3 data-levels 12 级描述；单级天赋（星赐天赋）自动适配。

### 5. 临阶·星赐（712px）
- 顶部说明文字 + **临阶段 Ⅰ-Ⅻ 横向 chips**（选中=品牌描边底）。
- 每阶 5 张礼物卡：礼物图标(72rpx) + 名称（带品质后缀 荧/烁/辉/耀/煌）+ 属性加成（带彩色小图标，品牌深色粗体右对齐）+ 类型/技能等级标签 + 消耗材料行（图标+名称+×数量）。
- 升阶块：--soft 底，升阶加成 + `Lv · 世界难度` 限制 + 消耗 + 附注「当阶加成在晋升至下一阶后生效」。

### 6. 定弦（886px）
- 10 个定弦条目块：名称粗体 + 效果文本，虚线分隔。

### 7. 推荐配置（2675px，三组）
- **奇波搭配推荐**：说明行 + 4 张奇波卡（横向条卡：图标+名称+定位标语+元素/编号+「推荐N」角标），**点击跳转奇波详情**。
- **灵子搭配推荐**：子标题「核心首选推荐/可选适配灵子」+ 12 张灵子卡（图标+名称+星级+满级主属性品牌色+专属技能名+描述）。
- **装备推荐**：配装口径行（星识等级/品质/倾向/数值标准）+ 15 张装备卡（槽位名+图标+名称+主属性+词条效果）。

### 8. 角色资料（465px）
- 信息键值对（元素主副/生日/配音/种族/所属势力，BWIKI 数据覆盖 CBT3 的「待公开」）+ 完整版角色简介段落。

### 9. 好感度（433px）
- Lv1-10 四列表（Lv / 所需经验 / 属性加成(带图标) / 好感奖励(带图标+数量)），无项显示「—」，表头灰字、行间虚线。

### 10. 角色故事（602px）
- 5 篇，二级标题 `Ⅰ · 一心向武` 格式（26rpx 粗体），正文 23rpx/1.7 行高。

### 11. 角色语音（6625px ⚠️ 占比 44%）
- 4 个分类组：资料档案(12) / 日常养成(49-50) / 地图探索(55) / 战斗交互(38)。
- 每条：条目名(168rpx 固定列宽粗体) + 内容文本（左名右文两栏式），组间虚线分隔。
- ⚠️ 全量平铺无折叠 —— 建议评估折叠/分页/按组页签。

### 12. 队伍按钮 + 脚注（44px）
- 全宽「编入队伍/移出队伍」主按钮（品牌实底白字，已入队变描边）+ 来源声明脚注（20rpx ink-3 居中）。

## 四、交互与状态汇总

| 交互 | 反馈 |
|---|---|
| 收藏 | 胶囊钮金色实底 + toast |
| Lv 切换（技能）/ 阶段切换（星赐） | chips 即时切换，无需确认 |
| 奇波推荐卡点击 | 跳转对应奇波详情（找不到进奇波列表） |
| 立绘点击 | 大图预览 |
| 编入队伍 | toast + 按钮态切换 |
| 图片加载失败 | 逐档回退（云图→CDN→热链→占位字形），占位为灰底字形块 |

## 五、已知观察点（供评估重点关注）

1. 语音区 44% 篇幅占比过高，无折叠。
2. 推荐配置 17.8%，卡片信息密度大，可评估分组页签化。
3. csxylic 热链图标（属性卡等）在源站慢时出现灰块占位（微信端已迁云存储，H5 端仍热链）。
4. 星赐/推荐配置等信息密集区在 375px 宽度下单卡内元素右对齐换行较频繁。
5. 双主题下对比度均已达标（正文 ink-2 与底色对比 ≥4.5:1）；装饰性弱文本（ink-3）约 3:1。
