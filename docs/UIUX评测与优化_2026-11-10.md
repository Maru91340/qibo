## 已确认的问题

| 优先级 | 问题 | 证据与影响 |
| --- | --- | --- |
| P0 | 通用图鉴清空筛选没有恢复用途条件 | 材料页先选“用途→可刷”再输入不存在的关键词，点“清空筛选”后用途栏恢复显示“不限”，但结果仍为 0；原因是重置对象漏掉 `usage`。 |
| P1 | 角色页横向快捷筛选在手机 H5 预览出现滚动条压住选项 | 390×844 视口截图中，快捷筛选区域底部出现横向滚动条，滚动条与选项视觉重叠；微信端仍需在 320/375/390/430px 真机或开发者工具复测。 |
| P1 | 通用图鉴用途标签使用硬编码浅色 | 深色主题下“养成/可刷”标签的固定颜色与背景对比偏弱，且无法随主题统一调整。 |

| P1 | 数据可信度提示较多 | 多个页面同时出现“待核实、示例、BWIKI、云端尚未同步”等提示；这是内容治理问题，本轮未改数据口径。 |
| P2 | 工具页和内容页的标题结构已统一，但页面任务层级仍有差异 | 入口可用，后续可按“查询、编队、计算、阅读”重新归组，避免首页目录继续堆叠。 |

## 本次代码优化

实际只修改了 `src/components/catalog-list/catalog-list.vue`：

1. `resetFilters()` 重置对象补上 `usage: '全部'`，清空筛选后列表恢复完整结果。
2. 用 `cl-usage--growth`、`cl-usage--other` 语义类替换用途标签的硬编码颜色，颜色改用主题变量，深色模式更易读。
3. 本页缺图占位的触控尺寸统一到 44px 基准，筛选展开区最大高度改为视口 45%，降低长筛选项挤压内容的风险。

没有修改 `src/styles/theme.css`、`src/styles/content.css`，也没有改动其他页面、数据、注释或图片文件。文件原有 CRLF 换行保持不变。

## 后续建议

- 在微信开发者工具中复测角色页和奇波页的横向筛选，重点看滚动条是否仍遮挡选项；若仍存在，应只调整两个页面的 `.cl-quick-scroll` / `.cl-quick-track` 高度与滚动条表现。
- 对 320、375、390、430px 宽度分别检查：搜索框、筛选 chip、排序、收藏按钮、卡片摘要和空态按钮。
- 抽查角色头像和奇波图标是否与对象对应；头像、详情立绘、攻略长图不要共用同一个图片用途字段。
- 深色模式继续检查首页和详情页中写死的颜色，确保正文和标签均使用主题语义变量。
- 公测倒计时、订阅页和来源文案应以同一资料版本验收；H5 能加载不等于微信小程序端云端数据已同步。
