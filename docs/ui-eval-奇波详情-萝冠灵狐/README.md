# 奇波详情页 UI 设计说明 —— 以「萝冠灵狐（NO.3）」为样例

> 用途：提供给 AI 做 UI 评估的完整上下文。数据取自 390×844 移动视口下的实测（uni-app H5 构建，与微信小程序端同一套组件与样式），截图 14 张见同目录附件。
> 页面路由：`/pkg-qibo/detail?id=<奇波id>`（示例：`?id=qi-80614efc75` 萝冠灵狐，木系·苍林·成熟期·NO.3）

## 三、各板块明细

### 0. 头部 hero（337px，元素渐变实底）
- 立绘白底圆角卡（aspectFit）+ 右上「☆收藏」胶囊（收藏后金底）+ 右下「🔍 查看大图」胶囊。
- 名称行：`萝冠灵狐` 大号白字粗体 + `NO.3` 品牌色小徽标。
- chips 一行：木（元素）/ 成熟期 / 200cm 中 / 异生类·兽形族（白色 22% 透明底胶囊）。
- 交互：立绘/查看大图 → 图片预览；收藏切换。

### 1. 六维能力资质 RADAR（248px）
- 3 列 × 2 行 tile（--soft 底）：彩色圆角图标底座（攻击=红剑/生命=绿心/防御=蓝盾/破韧=紫爪/超限=绿波）+ 属性名 + 数值 + 等级徽标（D/S，S 级金黄）。
- **暴击率 43.6% S 为高亮特例**：金黄底 + 上涨箭头 —— 六维中的优势项强调。

### 2. 技能 SKILLS（848px，整页最大板块）
- 页签：`战斗技能 4`（选中蓝底白字圆角）/ `对决技能 4`。
- 技能卡 ×8：图标（72rpx，含 Lv.1 蓝色角标）+ 名称 + 元素标签（木）+ 类型标签（特技/技能/合击）+ 消耗行（⏱17秒 ⚡80）+ **Lv.1-5 chips**（描述随等级切换数值）+ 描述 + 「战斗机制与数值解析（1 段攻击）· 展开解析」折叠行。
- 三级数值以官方为准脚注。

### 3. 专属特性 TRAIT（163px）
- 名称 + 标签（专属固有特性 / 不受控）+ 描述行。

### 4. 基因技能（336px）
- 基因卡：名称（开心果）+ 标签链（先天必带 / 卓越 / 伤害提升类）+ 战斗开场效果描述。

### 5. 基础分类与特征（368px）
- 键值对组：进化阶段=成熟期 / 体型=200cm 中 / 异生类·兽形族 等基础档案。

### 6. 家园（274px）
- 基础生产周期 360秒（6分钟）、耕作=初级 等家园产能键值。

### 7. 家族·萝冠灵狐系（179px）
- **进化链横向滚动卡**：小芽狐(幼年期) → Lv40 → 蓬尾狐(成熟期) → Lv60 → 萝冠灵狐(高成熟期)，当前形态描边高亮，点击可切换详情。

### 8. 星临图志 ATLAS（220px）
- 图志加成 chips（攻击 +16 / 攻击 +24 / 物理防御 +4 / 生命 +80）。
- 折叠行：技能释放（共5项）/ 等级（共7项）/ 潜能（共6项）/ 图志等级与奖励（10级）。

### 9. 奇波升级经验 EXP（375px）
- 三列表（Lv / 升下级 / 累计），里程碑行 1/20/30…100，底部「展开全等级（100 级）」折叠。

### 10. 同元素奇波（150px）
- 横向头像卡 ×8（叶冠驼、小芽狐、拉缇亚、木兜兜…），点击跳转对应奇波详情。

### 11. 元素相克参考（224px）
- 克制 / 被克制 元素 chips（烈焰、流水…十元素）。

### 12. 出战按钮 + 脚注（83px）
- 全宽「设为出战奇波」主按钮（品牌实底白字）+ 来源脚注。

## 四、交互与状态汇总

| 交互 | 反馈 |
|---|---|
| 收藏 / 查看大图 | 胶囊态切换 / 大图预览 |
| 战斗技能 ↔ 对决技能 | 页签切换 |
| 技能 Lv.1-5 chips | 描述数值随档位切换 |
| 进化链卡 / 同元素卡点击 | 跳转对应奇波详情 |
| 展开解析 / 展开全等级 / 图志折叠行 | 折叠展开 |
| 设为出战奇波 | 主按钮提交 |

## 五、已知观察点（供评估重点关注）

1. 技能区占 20.1%，8 张技能卡结构重复（图标+标签+消耗+Lv chips+描述+折叠解析），可评估页签内卡片密度与折叠默认态。
2. 基因技能/专属特性/星临图志三个小型板块信息各不满一屏，可评估合并为「特性」组的可能性。
3. 元素相克参考为静态科普内容，位于页面尾部，可评估是否下沉或弹窗化。
4. 头部 hero 绿色渐变（木系）与全站品牌蓝的融合度。
5. 双主题令牌一致；深色下六维彩色图标底座对比度良好。
