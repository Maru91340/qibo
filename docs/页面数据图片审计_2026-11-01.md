## 三、用户报告问题的核查结论

| 「奇波详情页都没有数据」 | H5 实测 435 字/5 面板（三角蜥）✅。微信端请确认：① 已用**最新 dist**（技能/相克面板是近两日新增）② 清缓存后编译（内置版本升级会自动清过期云端缓存）③ 是否点到空态条目（收藏/搜索里的旧 id 会显示「未找到」） |

| 「敌人/副本图鉴缺图片」 | **属实，无解于现有数据源**：BWIKI 无敌人/副本分类（已穷举探测），全站搜索也无独立 BOSS 图鉴页 |

## 四、外部数据源调研结论

| 数据 | 调研结果 | 结论 |
|---|---|---|
| 敌人/BOSS 图鉴 | 9game/游民/游侠均无独立图鉴页；BOSS 信息分散在地区委托攻略与奇波图鉴（游戏内敌人多为奇波亚种） | **无抓取源**。建议：敌人图鉴改名为「野生奇波与亚种」并入奇波数据，或维持手工待公测 |
| 角色立绘/头像 | 官网 azurpromilia.com、TapTap 官方动态、微博「星原吟游的图绘」系列有高清立绘；BWIKI 角色页内嵌图已抓（18/24） | 公测后官网/官方动态可系统化补充；当前真头像已够用 |
| 游侠手游角色数据 | 有详细技能倍率文本（如「680%攻击力的水属性伤害」） | 可作为 BWIKI 的技能校对源（robots 需检查） |
| Steam 创意工坊 | 4K 动态壁纸素材（忒拉拉/寒悠悠/夏儿） | 壁纸画廊可扩源（注意版权标注） |
| 官方 API | 无公开图鉴 API | 公测后抓包是唯一结构化途径（注意服务条款） |

## 五、建议的定时持续开发方向（供决策）

| 优先级 | 方向 | 说明 |
|---|---|---|
| 高 | 每轮采集后自动核对图片覆盖率并汇报 | 现有定时任务已做，数据随 BWIKI 更新自动跟进 |
| 中 | 敌人图鉴从攻略文章结构化提取 | 9game 等攻略文含敌人信息，可按篇解析（需逐篇适配，成本中） |
| 中 | 灵子/物品 desc 用「获取方式」补齐 | BWIKI 页有获取方式标题，正文多为空——收益有限 |
| 低 | 角色星赐/定弦（养成材料/牵绊）提取 | 结构复杂、数值公测会变，暂缓 |
| 低 | 双属性克制表进对比页 | 数据已就绪（dualCounters），UI 可扩展 |

## 六、微信端复测指引（针对「详情没数据」）

1. 确认导入的是 `dist/build/mp-weixin` **最新构建**（今天多次重建）
2. 详情页 → 清缓存 → 全部清除 → 重新编译（内置资料版本升级后自动清过期云端缓存）
3. 从**列表点进**详情（勿用旧收藏/搜索历史里的旧 id，会显示「未找到」空态）
4. 若仍为空：详情页截图 + 条目名发我，逐条排查
