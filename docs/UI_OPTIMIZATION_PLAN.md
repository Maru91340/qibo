## 单轮产出下限（v2 核心规则）

过去的批次（B6–B8 每批 4–6 页）执行下来单轮产出偏少。自 v2 起，**每轮必须完成一个完整纵向切片**，达不到下限就不算完成本轮：

| 维度 | 下限要求 |
| --- | --- |
| 页面数量 | ≥ 8 个页面/路由；或「1 个共享引擎 + ≥ 4 个页面」；剩余批次不足 8 页时必须合并执行 |
| 代码范围 | 必须同时包含**数据 + 页面/组件 + 交互 + 空态 + 深色适配**，不接受「只调 CSS / 只改文案」的轮次 |
| 共享沉淀 | 每轮至少抽出或复用 1 个共享组件/样式类，避免页面各写一套 |
| 实测 | 每轮至少 3 条 H5 交互实测（点击/筛选/搜索/持久化任选），并附 1 张浅色截图 |
| 校验 | `npm run check` + `npm run build:mp-weixin` 双通过；任一失败不得标记完成 |
| 文档 | 回填本文档批次状态/执行记录、README 页面统计、接续记录；新增规则回写 [UI_STYLE_GUIDE.md](UI_STYLE_GUIDE.md) |
| 诚实数据 | 未核实内容必须带「待核实」或「公测后开放」标识，不编造官方数值 |

**拆分禁令**：不得为「每轮只做一点」而拆批。若某批天然很小，与相邻批次合并成一轮。每轮结束时必须让至少一个页族从「占位/粗糙」变成「可完整走通」。

## 每批验收标准

1. `npm run check` 通过（53 页面 / 16 类资料 / 组件 parity）。
2. `npm run build:mp-weixin` 成功；涉及视觉的批次同时在 H5 截图走查（浅色+深色）。
3. 新样式全部引用 Token 变量，无新增硬编码近似色；深色主题无白底黑字残留。
4. 可点元素有按压反馈；空态有主操作；筛选有命中数反馈。
5. 诚实规范：示例/未核实数据带「待核实」或「公测后开放」标识。
6. 达到「单轮产出下限」表全部要求。
7. 在本文档更新批次状态 + 执行记录；如有新沉淀规则回写 [UI_STYLE_GUIDE.md](UI_STYLE_GUIDE.md)。
