3. **热链预算不达标**：抽样 PNG 单张 17–110KB，「首屏缩略图均值 ≤15KB」按现有方案无法满足；本地 WebP 变体（1535 张 / 14.16 MB）仍未进入运行时。
4. **302 与运行表现未验证**：`Special:Redirect` 在微信 `<image>` 下的跳转、图片失败重试点击、长图封面裁切观感、深色占位对比度，全部没有运行证据。
5. **旧云端缓存仍可能压制磁盘新数据**（#20）：本轮所有代码改动不能表述为「运行界面已生效」。
6. 内容页非攻略条目的 `hashIndex` 随机灵子封面仍存在（H02 范畴，阶段 4.2 处理）；首页 `hashIndex` 同样未动。
