### 1.2 现场采集方法与边界

- 窗口枚举：`ctypes` 只读枚举可见顶层窗口 → 唯一带标题的小程序窗口 `蓝色星原小助手`（`WeChatAppEx` pid 26572、hwnd 4590436、`Chrome_WidgetWin_0`、745,122–1175,910、430×788、未最小化）。另有 `蓝色星原助手`（pid 27492，微信开发者工具）处于最小化。
- 抓图：`.NET Add-Type` 被宿主安全策略禁用；`PrintWindow` / `gdigrab -i hwnd|title` 直取 Chromium 窗口只得白屏（2645 字节）。最终改用 `ctypes` 短暂置前 + `ffmpeg -f gdigrab -i desktop -vf crop=430:788:745:122` 抓桌面裁剪，7 张均 156–360 KB 且内容可读。
- 点击范围：仅「角色图鉴」「奇波图鉴」两张入口卡、左上返回箭头、底部「首页 / 攻略」tab；**未点击「立即关注」「前往关注」「公告」「交流群」等外部动作**，采集结束恢复首页 tab 并取消置顶。
- 已知干扰：现场「角色图鉴」截图右上有「试试拖拽调节窗口大小 ×」气泡，为微信 PC 客户端宿主提示，**不是竞品 UI**，本报告未将其计入竞品设计。
