## 5. 已知取舍与遗留

1. **主视觉高度**：方案 5.2 给出两条路径，当前唯一已核验主视觉自带大标题，硬裁成 144px 窄条会裁掉日期文字；本轮按**备选路径**（完整 16:9 `aspectFit` 展示 + 下方独立文字条）实现，媒体区约 201px，较 H01 的 140–150px 预算多约 57px，第二类预览相应后移。是否接受该选型、或改用无字横图 / 纯事件文字卡，见新增待确认 **#25**（默认跳过＝维持备选，不做 390px 视觉验收）。
2. **H03 承接内容**：落地 `/pages/about/about` 目前只有公测日期标签与资料来源说明，不构成「完整公测信息专题」；4.7（H09 事件收敛）与 4.9（H11 术语）需补齐，或按 #25 授权新建承接页。
3. **2.6 预算脚本口径过时**：`scripts/verify-image-budget.mjs` 的「当前首页 23 个图片节点 / 首页主视觉无 @error」仍按旧 `hashIndex` 随机配图模型模拟，自 4.2 起不再对应实际首页；本轮**未修改**该脚本与其 2.6 报告（已完成项不重复生成）。新首页口径见本报告第 3 节（模板 3 节点 / 运行时 9 图片位）。后续轮次需修订预算脚本后重算首屏预算；按 #21 默认仍维持热链，缩略图均值 87.1 KiB、首屏合计 641.0 KiB 的历史结论**不作为本轮性能通过依据**。
4. **包体余量**：主包 1929.1 KiB，硬上限余量仅 16.5 KiB；后续 4.4–5.3 若继续新增模板/样式须防触发 1.9MB 硬上限。全量图片未进 `src/static`，WebP 变体仍未分发（#15 / #21）。
