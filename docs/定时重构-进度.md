1. **本地 http.server 无 no-cache 头，浏览器会缓存旧 index.html**——构建后验证必须带 cache-bust 参数（?v=时间戳）或强刷，否则截图/DOM 断言可能来自旧构建；IAB 面板视觉缩放可能造成截图假象，视觉存疑时一律以 DOM 断言为准。
2. **vite 对页面样式的 CSS chunk 分包不可依赖**（两处实锤：character/list 双列规则、character/detail 收藏位样式均被分包漏加载）。多页面共用的 UI 模式样式（双列卡、收藏位）一律收敛到 theme.css 全局，页面内只留页面私有样式。
