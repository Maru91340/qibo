# 01｜全局视觉设计规范

## 设计目标

面向《蓝色星原》玩家，包含青少年用户。整体要有游戏感、轻快、清晰、有活力，但不幼稚、不堆砌装饰。奇波和角色立绘是视觉主角。浅色和深色主题共享同一套组件结构。

## 推荐方向

「星原探索感 +
轻量游戏图鉴」：清爽明亮的蓝色为品牌色，青绿色用于收集/成功，暖金色用于稀有度/奖励；浅色用带微蓝的浅灰背景与白卡，深色用深海军蓝背景与蓝灰卡。

## 建议设计令牌

以下是改版起点，开发前先检查现有主题系统，再决定兼容/迁移方式。

  Token                浅色        深色        用途
  -------------------- ----------- ----------- ------------------

  `--brand-strong`     `#2454D6`   `#8EAEFF`   强调文字

## 双主题

-   浅色为默认基准；深色逐组件适配，禁止简单全局反色。
-   深色避免纯黑大背景。
-   卡片、输入框、筛选面板、底部抽屉、分割线、禁用态和空状态均需检查。
-   选中态不能只依赖颜色，还要有图标、描边或文字反馈。
-   语义固定：蓝=主操作，绿=已收集/成功，金=稀有/奖励，红=危险/错误。

## 排版与间距

以 750rpx 设计稿为基准，兼容项目现有单位： - 页面左右边距 24--30rpx。 -
一级卡片圆角 22--28rpx；次级块 14--18rpx；chip 全圆角。 - 一级标题
32--36rpx；卡片标题 27--30rpx；正文 23--26rpx；辅助说明 20--22rpx。 -
卡片内边距 22--28rpx，卡片间距 18--22rpx。 -
数值使用等宽数字；长文本、窄屏和缺失字段要有稳定布局。

## 卡片与图片

-   图鉴卡片中图片第一、名称第二、标签/摘要第三。
-   奇波图常见 200×200px，建议显示容器约 88--112rpx，使用
    `aspectFit/contain`，透明背景可配柔和底座。
-   编号轻量化；元素标签用元素色；普通标签用中性底色。
-   收藏与已收集必须是两个独立状态。
-   图片失败使用统一占位，不出现裸灰块。
-   Hero
    使用元素主题柔和渐变，只作用于头图区域；立绘容器干净清晰，收藏位置固定，可预览大图。

## 动效

只使用轻量、短促、可预期的按压、选中、收藏反馈和折叠动效。避免闪烁、强弹跳和大面积粒子效果。
