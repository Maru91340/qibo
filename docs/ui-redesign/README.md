# 奇波小助手 UI 改版文档包

项目：奇波小助手（uni-app / 微信小程序）。本目录作为 Codex、Claude Code
等本地 AI 编程工具的长期设计依据。

## 阅读顺序

1.  `01-全局视觉设计规范.md`：全站颜色、字体、间距、卡片和双主题。
2.  `02-图鉴页面设计规范.md`：奇波/角色列表与详情。
3.  `03-交互与功能规范.md`：搜索、筛选、排序、收藏、已收集、吸顶导航。
4.  `04-页面改造实施计划.md`：阶段、验收、风险控制。
5.  `05-AI持续开发总提示词.md`：每次开发前提供给 AI 的总提示词。
6.  `06-参考资料与截图索引.md`：参考截图和素材登记。

## 项目现状

-   技术：uni-app，微信小程序为主要运行端，另有 H5 构建调试。
-   后端：微信小程序云开发；云函数提供接口，云数据库存数据，云存储放图片。
-   不依赖自建业务域名。
-   首页通过 `meta.js` sections 组织入口，已知 38 个去重后的子页面。
-   核心优先级：奇波图鉴、角色图鉴；角色目前约 24 个，预计增长到 40--50
    个。
-   详情路由：`/pkg-qibo/detail?id=<奇波id>`、`/pkg-character/detail?id=<角色id>`。
-   已有浅色/深色主题；详情 Hero 使用元素/角色主题渐变。
-   奇波图片常见尺寸约 200×200px，列表和详情优先完整显示，避免裁切。

## 核心原则

优先提升视觉设计、配色、卡片美观度和信息直观性；保留现有功能、接口、数据结构和云开发安全控制。渐进式改造，不推翻重写。
