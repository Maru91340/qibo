# 02｜图鉴页面设计规范

优先改造奇波与角色图鉴，其他图鉴后续复用统一组件。

## 奇波列表

结构：顶部导航 → 搜索 → 元素/阶段快捷筛选与更多筛选 →
结果工具栏（总数、已收集数、排序）→ 图鉴卡片 → 空/加载/错误状态。

两列网格可作为候选方案，但必须用真实名称长度、图片比例和标签验证；若拥挤则保留单列横向卡片，不为模仿竞品强行改布局。

卡片展示：图片、编号、名称、元素、阶段、1--2
个重要特征、已收集状态、收藏状态。图片完整显示；卡片点击和收藏/收集按钮点击区域分开。

## 角色列表

角色约 24 个，预计增至 40--50
个。突出立绘和角色身份：立绘/头像、名称、稀有度、元素、武器/定位、收藏、已拥有/已收集（仅当现有业务支持）。列表用缩略图、懒加载，避免加载原尺寸大图造成卡顿。

## 奇波详情

路由 `/pkg-qibo/detail?id=<奇波id>`。保留现有
Hero、六维资质、战斗/对决技能、专属特性、基因技能、基础分类、家园、进化链、星临图志、升级经验、同元素奇波、元素相克、出战操作。

推荐顺序： 1.
Hero：图片、名称、NO.编号、元素/阶段/体型/种族、收藏、查看大图。 2.
战斗信息：六维能力资质，3×2 数据卡；优势值轻强调。 3.
技能：战斗/对决页签，等级切换；复杂机制解析默认折叠。 4.
特性：专属特性和基因技能分组呈现。 5. 基础信息与家园。 6.
家族进化链：当前形态高亮，可跳转。 7. 星临图志：摘要展示，细项折叠。 8.
升级经验：默认里程碑，完整 100 级按需展开。 9. 同元素奇波、元素相克。
10. 底部设为出战操作与来源说明。

不要删除原始数据；折叠只改变展示。技能等级、进化链、关联卡片保持现有交互和路由。

## 角色详情

路由 `/pkg-character/detail?id=<角色id>`。采用「吸顶式导航 +
分类堆叠」，不改成复杂多级页面。

建议导航：总览、属性、技能、养成、配置、档案。点击定位到区块，手动滚动时同步高亮。处理微信导航栏、安全区、滚动容器和图片异步加载造成的定位偏差。

内容分组： 1. Hero + 角色简介。 2. 属性：基础战斗、进阶战斗、元素加成。
3. 技能：等级切换、技能类型标签、长描述清晰分段。 4.
养成：临阶·星赐、定弦。 5.
配置：奇波、灵子、装备，建议内部页签或折叠分组。 6.
档案：角色资料、好感度、角色故事、角色语音。 7. 编入/移出队伍操作。

角色语音当前约占页面总高度
44%，默认折叠或仅展示部分条目，按资料档案、日常养成、地图探索、战斗交互分组。故事可按篇章折叠。推荐配置按类别分组。不得删除资料。

## 适配

以 375px/390px
手机视口检查；兼容刘海、安全区、微信胶囊；无横向溢出；长名称、长技能文本、缺失字段均有稳定布局。长列表注意懒加载和节点数量。
