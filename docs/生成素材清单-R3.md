## 存储与回写方案（按优先级）

1. **微信云存储 CDN（推荐）**：`--apply` 出图后上传云存储 → https CDN URL → 回写 icon 字段 → collect 管道固化。依赖云环境部署凭证（见待审批）
2. 分包 static：enemy/dungeon/region 页均在主包，**不可用**（分包资源仅本分包可见）
3. 主包 static：**不可行**（余量仅 80.6KiB，31 张 ≈ 600KB+）
4. 极限压缩兜底：256² webp q70 ≈ 8KB × 31 = 248KB 仍超余量 → 放弃
