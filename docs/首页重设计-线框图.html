深色模式不是把浅色稿整体反相，而是重新定义表面层级、文本对比和行为色。下列令牌与生产代码保持一致。

设计规则
  • 三层表面：页面底 → 主卡 → 次级托底，依靠明度差建立结构，不用厚阴影。
  • 行为色分离：实心按钮/指示条继续用主蓝；小号链接改用亮蓝，避免暗底低对比。
  • 图标统一：emoji 置于低饱和蓝色托底，边缘增加极轻品牌色描边。
  • 图片例外：Hero 图片、叠层白字、白色倒计时胶囊不随主题反转。
  • 原生界面：深色导航栏与回弹区域同步为 #151C2B / #111621，避免露白。
