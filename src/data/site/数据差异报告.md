## 3. 数据与图片的对应关系

### 3.1 关联键（按可靠性排序）

1. **站点 SMW「图片」属性 → 采集清单原始文件名**：灵子/物品/装备/料理/建筑/书籍 共 1673 条全部命中，新增条目同样适用。
2. **数据 `icon` 缩略图 URL 的 CDN 哈希 → 采集清单原图直链**：用于角色/奇波/攻略（站点无「图片」属性），本地 2010 个 icon 中 2009 个命中。
3. **角色 ID → `Tex_icon_hero_l_<id>.png` 等专用素材**：从 `hero_get_<id>` 提取，源千代由站点 wikitext `|id=104001` 补齐。
4. **奇波 ID → `Tex_pet_kibo_card_kibo_<id>.png` 卡面**：从 `Tex_icon_pet_<id>.png` 提取。

## 5. 后续接入说明（本轮不执行）

1. 复评文档阶段 B/C 接入时，用 `site-catalogs.json` 替换 `src/data/generated/catalogs.json`，并同步 `catalogs-bundled.json` 与 `npm run seed:export`（`check.mjs` 会校验 seed 修订号）。
2. `catalog.js` 的 `collected()` 目前会给非 `http` 的 `icon` 拼 CDN 前缀，因此新数据的 `icon` 仍保留站点 URL；本地图片请通过新增的 `images.<用途>` 字段读取，不要直接改 `icon`。
3. `src/assets/wiki/` 未被任何模块 import，uni-app/Vite 不会把它打进主包（`check-package-size.mjs` 只扫描 `dist/build/mp-weixin` 构建产物）。当前主包产物约 1865.6 KiB，已超过 1689.6 KiB 安全预警线，**全量图片不能直接塞进 `src/static/`**；正式使用时按页面需要挑少量图片或上传 CDN，遵守复评文档 5.4 的包体预算。
4. 采集素材来自第三方玩家 Wiki，公开可访问不等于可用于产品，上线前需确认使用条件。
